asynchronous non-blocking callback minions
 
* what are some things that you might need to wait for? * not waiting enables you to keep doing stuff * whether evil or not
  • goal: keep code shallow
    • fewer nested levels are easier to read
    • less error prone
  • some solutions for nested callbacks:
    • use named functions
    • use modules
    • promises
    • async/await
 
escaping callback hell?
 
* fewer levels is easier to read
  • rather than passing a callback:
    • return a promise that will be filled when done
  • promise represents result of asynchronous operation:
    • pending - initial state of a promise
    • fulfilled - successful operation
    • rejected - failed operation
